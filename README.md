# OpenDoor 2D

A browser-based 2D side-view horror game prototype.

## Features

- 2D side-view rooms
- Mouse-directed facing and flashlight
- WASD movement
- Health bar HUD
- Doors and room progression
- Tables and cabinets
- Collectible coins
- Interactable objects

## Run

Open index.html in a modern browser.

For best results, use a local web server.
